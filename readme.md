# Gestor de Materiales y Pedidos

Proyecto práctico desarrollado en Java con el objetivo de aplicar de forma progresiva los conceptos estudiados durante mi formación.

La aplicación se irá construyendo por etapas, empezando por una gestión básica de productos y stock y ampliándose posteriormente con pedidos, colecciones, validaciones, persistencia y pruebas.

## Objetivo

Construir un gestor sencillo de materiales y pedidos utilizando Java, aplicando buenas prácticas de programación orientada a objetos y aumentando la complejidad del proyecto conforme avance el aprendizaje.

## Tecnologías

- Java
- Maven
- IntelliJ IDEA
- Git / GitHub

## Estado actual

Proyecto en fase inicial.

Primera etapa:

- Creación de productos.
- Gestión básica de stock.
- Consulta de existencias.
- Entrada de unidades.
- Retirada de unidades.
- Rechazo de retiradas superiores al stock disponible.

## Etapas previstas

1. Producto y gestión de stock.
2. Pedidos y líneas de pedido mediante composición.
3. Catálogo de productos y búsquedas mediante colecciones.
4. Validación de operaciones mediante excepciones.
5. Consultas y operaciones con Streams.
6. Persistencia en archivos.
7. Persistencia en base de datos cuando el proyecto alcance esa fase.
